# Lite Mode prototypes

Interactive iHeart Home prototypes comparing ways to switch between Discover and Lite. All four share the same content; only the control changes.

- `live/` Live today, Lite switch in the header
- `e2/` Option E2, segmented control, Inset 4
- `fix2/` Fix 2, segmented control with recessed track
- `f/` Option F, Discover | switch | Lite toggle

Edit `src/template.html`, then run `python3 build.py` to regenerate the four pages.
