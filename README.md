# Lite Mode prototypes

Interactive iHeart Home prototypes comparing ways to switch between Discover and Lite. All share the same content; only the control changes.

- `version-a/` Version A, live today, Lite switch in the header
- `version-b/` Version B, segmented control (Option E2, Inset 4)
- `version-c/` Version C, Discover | switch | Lite toggle with equal halves (Option F3)
- `fix2/` Fix 2, segmented control with recessed track
- `f/` Option F, Discover | switch | Lite toggle

The old `live/`, `e2/` and `f3/` links forward to Versions A, B and C.

Edit `src/template.html`, then run `python3 build.py` to regenerate the pages.
